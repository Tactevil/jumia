# jumia
Overview

This project investigates whether Jumia Kenya's aggressive discount campaigns (60–80% off) represent genuine bargains or deceptive marketing tactics that disguise poor-quality products and unreliable sellers. Using data scraped from 1,350+ technology products across 8 categories, we analyze the relationship between discount depth, product ratings, review counts, and seller reliability — and build a reusable "Deal Authenticity Score" to help Kenyan shoppers make smarter buying decisions.

Core hypothesis: Products with excessively high discount percentages (>60%) are likely to have lower ratings, fewer reviews, and come from less reputable sellers. Deep discounts are often a red flag rather than a genuine bargain.

🎯 Project Goals
Quantify the correlation between discount percentage and product rating
Identify which categories and brands offer genuine value vs. deceptive discounts
Detect price tiers where discount deception is most prevalent
Build a Deal Authenticity Score consumers can use to spot-check any listing
Tell the story through an interactive, non-technical Tableau narrative
